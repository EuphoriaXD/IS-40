1) Установить Windows 10 на ВМ 1 поколения;
2) Удалить раздел восстановления утилитой diskpart, сжать системный раздел (оставить место для копии);
3) Сжать виртуальный диск до минимального размера, растянуть системный раздел на оставшееся пространство;
4) Снять копию системного диска утилитой Disk2vhd (имя файла "copy-dynamic.vhdx"; использовать технологию теневого копирования);
5) Разместить копию в каталоге виртуальных дисков Hyper-V;
6) Преобразовать копию в фиксированный диск (имя файла "copy-fixed.vhdx"; клонировать содержимое на новый диск);
7) Подключить диск к ВМ 1 поколения;
8) Создать раздел восстановления:
	- Сжать системный раздел на 1 ГБ;
	- Создать новый раздел на 1 ГБ;
	- Проверить наличие файла "C:\Windows\System32\Recovery\Winre.wim";
	- Если файл отстутствует, скопировать его из %установочный_диск%\sources\install.wim (открыть файл с помощью 7-Zip, перейти в "1\Windows\System32\Recovery");
	- Запустить утилиту diskpart, выполнить команды:
		- list disk;
		- select disk %номер_системного_диска%;
		- list partition;
		- select partition %номер_раздела_восстановления%;
		- set id=27;
		- exit.
	- Запустить командную строку, выполнить команды:
		- reagentc /enable;
		- reagentc /info.
9) Выполнить преобразование структуры разделов утилитой MBR2GPT;
10) Подключить диск к ВМ 2 поколения;
11) Выполнить загрузку системы.
