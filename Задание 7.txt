Задания:
1) Установить Windows 8.1 на виртуальную машину (подобрать generic-ключ для установки);
2) Выполнить загрузку с образа Windows 8.1;
3) Запустить командную строку (Shift + F10);
4) Скопировать файлы cmd.exe и sethc.exe из папки Windows/system32 в корневой каталог диска C;
5) Заменить файлом cmd.exe файл sethc.exe из папки Windows/system32;
6) Загрузить систему в безопасном режиме;
7) Вызвать залипание клавиш (долгое нажатие на клавишу Shift);
8) В командной строке получить список пользователей;
9) Сменить пароль существующего пользователя;
10) Создать нового пользователя;
11) Выполнить загрузку с образа Windows 8.1;
12) Восстановить исходный файл sethc.exe;
13) Перезагрузить систему.
